# Results Directory

This directory stores generated experiment outputs.

## Structure

```text
results/
├── metrics/
├── plots/
└── tables/
```

---

# Metrics

The `metrics/` directory stores:
- experiment result CSV files,
- evaluation summaries,
- and aggregated performance metrics.

---

# Plots

The `plots/` directory stores:
- generated visualizations,
- robustness comparisons,
- efficiency plots,
- and cross-experiment figures.

---

# Tables

The `tables/` directory stores:
- summary tables,
- comparative experiment outputs,
- and export-ready analysis tables.

---

# Purpose

Centralizing generated outputs improves:
- reproducibility,
- experiment tracking,
- analytical consistency,
- and thesis integration.
