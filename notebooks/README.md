# Design Philosophy

The notebooks are intentionally lightweight and analysis-focused.

Core experimental logic is centralized inside the `src/` package in order to:
- improve reproducibility,
- reduce duplicated code,
- and separate implementation from analysis.

This structure allows the notebooks to function more as research-oriented analytical workflows rather than implementation-heavy scripts.
