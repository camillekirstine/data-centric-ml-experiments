# Source Code Directory

This directory contains the reusable source code used throughout the project.

## Structure

```text
src/
├── data/
├── experiments/
├── models/
├── visualization/
└── utils/
```

---

# Data

The `data/` module contains:
- dataset loading,
- preprocessing,
- feature engineering,
- and dataset export utilities.

---

# Experiments

The `experiments/` module contains:
- experiment pipelines,
- robustness configurations,
- degradation logic,
- and automated notebook execution.

---

# Models

The `models/` module contains:
- model initialization,
- model configuration,
- and evaluation utilities.

---

# Visualization

The `visualization/` module contains:
- plotting utilities,
- summary table generation,
- and result visualization logic.

---

# Utils

The `utils/` module contains:
- file saving utilities,
- helper functions,
- and shared infrastructure logic.

---

# Purpose

Separating reusable code from notebooks improves:
- modularity,
- maintainability,
- reproducibility,
- and experimental clarity.
