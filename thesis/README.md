# Relationship to the Project

The thesis is closely integrated with the experimental framework contained within the repository.

The project structure is designed to support:
- reproducible experimentation,
- consistent result generation,
- and direct integration between experiments and written analysis.

---

# Research Focus

The project investigates the relationship between:
- preprocessing quality,
- representation design,
- inductive bias,
- robustness,
- computational efficiency,
- and predictive performance in tabular machine learning.
